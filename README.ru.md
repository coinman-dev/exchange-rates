# Курсы валют — конвертер для Android

[English](README.md) · **Русский**

Конвертер валют в стиле нового дизайна Xe: карточки валют, мгновенный пересчёт,
встроенный калькулятор в поле суммы, графики и полноценная работа без интернета.
Приложение бесплатное, без рекламы и без переводов денег.

## Что уже работает

- **Конвертер.** Базовая карточка «Вы конвертируете» и список целевых карточек.
  Ввод в любую карточку мгновенно пересчитывает остальные. Под суммой — удельный
  курс вида `1 USD → 84.3300 RUB` и, по желанию, изменение за сутки. Карточка,
  в которую вводят сумму, остаётся над клавиатурой.
- **Калькулятор в поле суммы.** Выражения `20.62+50`, скобки, проценты по
  калькуляторной логике (`100+10%` = 110). Панель `+ − × ÷ =` всплывает над
  системной клавиатурой. Цифра начинает новое число, знак действия продолжает
  текущее. Принимаются и точка, и запятая, а также разделители разрядов.
- **199 активов:** 161 мировая валюта, 34 основные криптовалюты, 4 драгоценных
  металла. Русские и английские названия взяты из ICU, поэтому совпадают с
  системными. Поиск понимает код, название на двух языках, символ и устаревшие
  обозначения (`RUR`, `XBT`).
- **Режим «курс ЦБ».** Помимо рыночной середины доступны официальные курсы
  Центрального банка РФ, Центрального банка Турции и Национального банка
  Казахстана.
- **Работа без сети.** В APK вшит снимок курсов, поэтому конвертер считает с
  первого запуска. Каждое успешное обновление сохраняется в базу; в футере
  видно время данных и признак офлайна.
- **Графики** 1D / 1W / 1M / 1Y / 5Y с градиентной заливкой, перетаскиванием
  «прицела» по кривой и статистикой (минимум, максимум, среднее, изменение).
- **Оформление:** тёмная AMOLED-тема и светлая, русский и английский язык с
  переключением без перезапуска, от 0 до 6 знаков после запятой, разделители
  разрядов по желанию.
- **Фоновое обновление** через WorkManager с выбором интервала и ограничением
  «только по Wi-Fi».

## Источники данных

Курсы сводятся к опоре USD и объединяются по приоритету с проверкой на
правдоподобность. Ни один источник не требует ключа.

| Назначение | Источники по приоритету |
| :--- | :--- |
| Живой курс фиата | Coinbase → FloatRates → Frankfurter → open.er-api → fawazahmed0 |
| Криптовалюты | Binance → Coinbase → CoinGecko → fawazahmed0 |
| Металлы | Gold-API → fawazahmed0 → Frankfurter |
| Официальные курсы ЦБ | Frankfurter с фильтром по провайдеру (CBR, TCMB, NBK) |
| История для графиков | Frankfurter (фиат, металлы), Binance и CoinGecko (крипта), Yahoo Finance (внутридневной ряд по фиату) |
| Аварийный запас | `assets/initial_rates.json`, вшитый в APK |

Правила слияния: берётся источник с наивысшим приоритетом для типа актива,
у которого данные не просрочены; значение сверяется с официальным дневным
курсом Frankfurter и отбрасывается при отклонении больше 5 % для фиата, 15 %
для металлов и 25 % для крипты. Это защищает от ошибок масштаба, когда источник
отдаёт курс за 100 единиц.

Адреса и приоритеты источников можно переопределить удалённым манифестом
(`Endpoints.MANIFEST`) без выпуска новой версии. Пока манифест не опубликован,
работают значения из кода.

Атрибуция: open.er-api требует упоминания «Rates by exchangerate-api.com» — оно
показывается в диалоге «Курсы и источники». Цены криптовалют с Binance даны в
USDT и приняты равными доллару, о чём сказано в том же диалоге.

## Сборка

```bash
./gradlew :app:assembleDebug          # отладочный APK
./gradlew :app:assembleRelease        # релизный APK (R8), около 1,9 МБ
./gradlew :app:testDebugUnitTest      # 103 теста, включая проверку живых API
```

Релиз подписывается ключом из папки `secrets/`, которая в репозиторий не входит;
без ключа собирается неподписанный APK. Как устроена подпись и секреты для
GitHub Actions — в [`secrets/README.md`](secrets/README.md).

Требуется Android SDK с платформой `android-37.2`. Сборка идёт на JDK 21 (это
нужно Robolectric для SDK 36+), путь задан в `gradle.properties`; байт-код
приложения остаётся Java 17.

## Выпуск версий

Тег вида `v1.0.0` запускает на GitHub Actions сборку подписанного APK и
публикует его в разделе [Releases](../../releases). Тег с дефисом (`alpha`,
`beta`, `rc`) публикуется как пререлиз. Тег должен совпадать с `versionName` в
`app/build.gradle.kts`, а `versionCode` — расти с каждым выпуском. Описание
релиза берётся из `.github/release-notes/<тег>.md`, если такой файл есть:

```bash
git tag v1.0.0 && git push origin v1.0.0
```

## Стек

Gradle 9.7.1, Android Gradle Plugin 9.4.0 со встроенным Kotlin 2.2.10,
compileSdk 37.2, minSdk 26, Jetpack Compose (BOM 2026.09.00) с Material 3,
Hilt, Room, Retrofit 3 с kotlinx.serialization, DataStore, WorkManager.
График нарисован на Canvas без сторонних библиотек.

## Структура

```
app/src/main/
├── assets/           currencies.json, initial_rates.json (генерируются, см. tools/)
└── java/com/exchangerates/app/
    ├── core/         тема, парсер выражений, форматирование чисел, DI
    ├── data/         справочник, Room, сетевые источники, слияние курсов, репозитории
    ├── domain/       модели: Currency, RateTable, RateMode, HistoryPoint
    ├── presentation/ конвертер, обзор курсов, графики, настройки, выбор валюты
    └── work/         фоновое обновление
```

## Тесты

| Набор | Что проверяет |
| :--- | :--- |
| `ExpressionEvaluatorTest` | приоритет операций, скобки, проценты, разделители разрядов, ошибки |
| `AmountFormatterTest` | форматы сумм и курсов, адаптивная точность для крипты |
| `RateTableTest` | кросс-курсы, конвертация, изменение за сутки |
| `RateMergerTest` | приоритеты источников, просрочка, отбраковка выбросов |
| `CurrencyFilterTest` | порядок поиска, алиасы `RUR` и `XBT`, разделы |
| `PristineInputTest` | цифра заменяет подставленную сумму, знак действия продолжает её |
| `CurrencyCatalogTest` | разбор сгенерированных ассетов (Robolectric) |
| `CurrencyCardTest` | отрисовка карточки и панели операторов (Robolectric + Compose) |
| `ConverterScreenTest` | карточка с вводом остаётся над клавиатурой, список открывается с начала |
| `ScreenshotTest` | отрисовка экранов в PNG для экрана размером с Galaxy S21 |
| `LiveSourcesIntegrationTest` | разбор ответов живых API, включая все режимы ЦБ |

Последний набор обращается к сети: без неё он пропускается, а флагом
`-PskipLiveTests` отключается совсем.
